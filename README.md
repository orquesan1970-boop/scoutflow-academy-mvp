# ScoutFlow Academy MVP v0.1

Primera estructura real del proyecto web de ScoutFlow Academy.

## Qué incluye

- `index.html`: entrada principal de la web.
- `css/styles.css`: estilos visuales.
- `js/data.js`: datos de prueba.
- `js/app.js`: lógica de navegación y demo.
- `data/`: datos JSON para futuras pruebas.
- `database/`: estructura técnica de tablas.
- `docs/`: documentación del proyecto.
- `assets/`: logos, imágenes y recursos.

## Cómo abrir la demo localmente

Opción rápida:

1. Abrir `index.html` con doble clic.
2. Se verá la demo en el navegador.

Opción recomendada para desarrollo local:

1. Abrir la carpeta en Visual Studio Code.
2. Instalar extensión "Live Server".
3. Clic derecho sobre `index.html`.
4. Seleccionar "Open with Live Server".
